# LabSync

Lab equipment booking and inventory management website.

**Stack:** Vite + vanilla JavaScript + Supabase Auth/Postgres/RLS + Vercel.

Read [SETUP.md](./SETUP.md) for complete backend setup, administrator provisioning, local run, GitHub push and Vercel deployment.

Features:
- Student registration with pending admin approval
- Restricted two-email administrator access
- Electronics-focused equipment catalogue and stock counts
- Booking requests, admin approval and issue tracking
- Unique QR code per equipment asset code
- Camera QR scanning
- Return and damage reporting
- Overdue loan visibility
- Responsive dashboard
- Floating LabBuddy AI chat assistant powered by your Gemini API key (server-side)

Email workflow notifications are not included. A warm-white and teal interface inspired by the supplied LabSync screenshots, smooth transitions, and electronics-focused demo data are included.
